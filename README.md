# Smart Recipe Generator

A web-based recipe generator that helps users find recipes based on available ingredients.

## Features

- Search recipes by ingredients
- Recipe cards
- Food images
- Responsive design
- Dark mode

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a browser.
